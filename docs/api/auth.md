# 가입 · 로그인 · 로그아웃 API (BE-B)

공통 규칙·에러 형식은 [common.md](common.md)를 따릅니다.

## 개요

- 인증 방식은 그대로 `X-Device-Token`(UUID)입니다. JWT는 쓰지 않습니다.
- 아이디·비밀번호 가입은 **선택**입니다. 가입하지 않아도 `POST /api/users`로 받은 토큰만으로 쓸 수 있습니다.
- 가입해 두면 기기를 바꾸거나 브라우저 저장소를 지워도 로그인해서 **같은 양과 들판**으로 돌아올 수 있습니다.
- 가입하지 않은 사용자는 브라우저 저장소를 지우면 양을 잃습니다. 앱은 합류 직후 "가입해 두면 기기를 바꿔도 양을 지킬 수 있어요"를 안내하는 것을 권장합니다.

```
계정(아이디·비밀번호) ──1:1── 사용자(users) ── 양, 들판, 말풍선, 목도리
        로그아웃 = 토큰만 못 쓰게 함 (데이터는 그대로)
```

## POST /api/auth/signup — 가입

`X-Device-Token`은 **있으면 보내고 없어도 됩니다.**

| 헤더 | 동작 |
|---|---|
| 유효한 토큰 | 그 사용자(양·들판)에 계정을 붙입니다. 토큰은 **그대로** 유지됩니다. |
| 없음 / 모르는 값 | 새 사용자를 만들고 새 토큰을 줍니다. |

요청
```json
{ "username": "dubu01", "password": "pass1234!" }
```

| 필드 | 규칙 |
|---|---|
| `username` | 영문·숫자 4~20자. **대소문자를 구분하지 않습니다.** (`Dubu01`과 `dubu01`은 같은 아이디) |
| `password` | 공백 없는 영문·숫자·특수문자 8~72자. 한글은 쓸 수 없습니다. |

응답 `201`
```json
{ "deviceToken": "3f1c7a0e-6c1b-4a8e-9a63-0c1f5d2b7e11" }
```
가입하면 바로 로그인 상태입니다. 받은 토큰을 저장하세요.

| HTTP | code | 언제 |
|---|---|---|
| 400 | `VALIDATION_FAILED` | 아이디·비밀번호 형식이 규칙에 맞지 않음 |
| 409 | `DUPLICATE_USERNAME` | 이미 쓰는 아이디 |
| 409 | `ALREADY_HAS_ACCOUNT` | 이 토큰의 사용자는 이미 계정이 있음 (로그인하세요) |

## POST /api/auth/login — 로그인

요청 `{ "username": "dubu01", "password": "pass1234!" }`

응답 `200`
```json
{ "deviceToken": "9b2d4c10-1f3e-4d77-8a52-6e0a1c9f3b44" }
```

- 로그인할 때마다 **새 토큰**을 발급합니다. 받은 값으로 저장된 토큰을 바꾸세요.
- 같은 계정으로 다른 기기에서 로그인하면 **이전 기기의 토큰은 무효**가 됩니다. (계정당 토큰은 하나입니다.) 이전 기기는 다음 요청에서 `401 INVALID_DEVICE_TOKEN`을 받으니, 그때 로그인 화면으로 보내세요.

| HTTP | code | 언제 |
|---|---|---|
| 400 | `VALIDATION_FAILED` | 아이디나 비밀번호가 비어 있음 |
| 401 | `INVALID_CREDENTIALS` | 아이디가 없거나 비밀번호가 틀림 (어느 쪽인지 알려 주지 않습니다) |

## POST /api/auth/logout — 로그아웃

토큰 필요. 본문 없음. 응답 `204`.

- 지금 쓰던 토큰이 즉시 무효가 됩니다. 앱은 저장한 토큰을 지우세요.
- **데이터는 지워지지 않습니다.** 같은 계정으로 다시 로그인하면 이전 양·들판이 그대로 보입니다.
- 가입하지 않은 사용자가 로그아웃하면 새 토큰을 알 방법이 없어서 **그 사용자의 데이터에 다시 접근할 수 없습니다.** 앱은 가입한 사용자에게만 로그아웃을 보여 주세요.

| HTTP | code | 언제 |
|---|---|---|
| 401 | `INVALID_DEVICE_TOKEN` | 토큰이 없거나 이미 무효 |

## 알려진 한계

- 계정당 토큰이 하나라서 여러 기기를 동시에 로그인해 둘 수 없습니다.
- 토큰에 만료 시간이 없습니다. 로그인·로그아웃으로만 바뀝니다.
- 비밀번호 찾기·변경, 로그인 시도 횟수 제한은 MVP 범위가 아닙니다.
