# 가입 · 로그인 · 로그아웃 API (BE-B)

공통 규칙·에러 형식은 [common.md](common.md)를 따릅니다.

## 개요

- **회원만 이용할 수 있습니다.** 가입(또는 로그인)으로 받은 토큰이 없으면 어떤 API도 쓸 수 없습니다. (들판 미리보기, 데모 API는 예외)
- 인증 방식은 `X-Device-Token`(UUID) 그대로입니다. JWT는 쓰지 않습니다.
- 가입할 때 받는 **양 이름**이 그대로 양의 이름입니다. 들판을 만들거나 합류할 때 이름을 따로 받지 않습니다.
- 기기를 바꾸거나 브라우저 저장소를 지워도 로그인하면 **같은 양과 들판**으로 돌아옵니다.
- 초대 링크로 들어온 사람은 **가입(또는 로그인)한 다음 합류**합니다. 합류 전 구경하기(미리보기)는 가입 없이 됩니다.

```
계정(양 이름·이메일·비밀번호) ──1:1── 사용자(users) ── 양, 들판, 말풍선, 목도리
              로그아웃 = 토큰만 못 쓰게 함 (데이터는 그대로)
```

## POST /api/auth/signup — 가입

토큰 없이 호출합니다.

요청
```json
{ "sheepName": "두부", "email": "dubu@example.com", "password": "pass1234!" }
```

| 필드 | 규칙 |
|---|---|
| `sheepName` | 2~10자, 앞뒤 공백 없음. 이모지 한 글자는 1자. **중복 불가**(대소문자 구분). |
| `email` | 이메일 형식(`a@b.c`), 100자 이하. **대소문자를 구분하지 않습니다.** 인증 메일은 보내지 않습니다. |
| `password` | 공백 없는 영문·숫자·특수문자 8~72자. 한글은 쓸 수 없습니다. |

응답 `201`
```json
{ "deviceToken": "3f1c7a0e-6c1b-4a8e-9a63-0c1f5d2b7e11" }
```
가입하면 바로 로그인 상태입니다. 받은 토큰을 저장하세요.

| HTTP | code | 언제 |
|---|---|---|
| 400 | `VALIDATION_FAILED` | 양 이름·이메일·비밀번호 형식이 규칙에 맞지 않음 |
| 409 | `DUPLICATE_EMAIL` | 이미 가입된 이메일 |
| 409 | `DUPLICATE_SHEEP_NAME` | 이미 쓰는 양 이름 |

## POST /api/auth/login — 로그인

요청 `{ "email": "dubu@example.com", "password": "pass1234!" }`

응답 `200`
```json
{ "deviceToken": "9b2d4c10-1f3e-4d77-8a52-6e0a1c9f3b44" }
```

- 로그인할 때마다 **새 토큰**을 발급합니다. 받은 값으로 저장된 토큰을 바꾸세요.
- 같은 계정으로 다른 기기에서 로그인하면 **이전 기기의 토큰은 무효**가 됩니다. (계정당 토큰은 하나입니다.) 이전 기기는 다음 요청에서 `401 INVALID_DEVICE_TOKEN`을 받으니, 그때 로그인 화면으로 보내세요.

| HTTP | code | 언제 |
|---|---|---|
| 400 | `VALIDATION_FAILED` | 이메일이나 비밀번호가 비어 있음 |
| 401 | `INVALID_CREDENTIALS` | 이메일이 없거나 비밀번호가 틀림 (어느 쪽인지 알려 주지 않습니다) |

## POST /api/auth/logout — 로그아웃

토큰 필요. 본문 없음. 응답 `204`.

- 지금 쓰던 토큰이 즉시 무효가 됩니다. 앱은 저장한 토큰을 지우고 로그인 화면으로 보내세요.
- **데이터는 지워지지 않습니다.** 같은 계정으로 다시 로그인하면 이전 양·들판이 그대로 보입니다.

| HTTP | code | 언제 |
|---|---|---|
| 401 | `INVALID_DEVICE_TOKEN` | 토큰이 없거나 이미 무효 |

## 알려진 한계

- 계정당 토큰이 하나라서 여러 기기를 동시에 로그인해 둘 수 없습니다.
- 토큰에 만료 시간이 없습니다. 로그인·로그아웃으로만 바뀝니다.
- **비밀번호를 잊으면 복구할 방법이 없습니다.** 이메일 인증과 비밀번호 찾기·변경, 로그인 시도 횟수 제한은 MVP 범위가 아닙니다.
- 양 이름은 가입 후 바꿀 수 없습니다.
